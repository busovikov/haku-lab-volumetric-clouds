01

Облака, у которых есть внутренний свет

Raymarching слоя с неодинаковой высотой клубов, процедурным 3D-шумом и встречным движением деталей. До 32 движущихся источников света и независимые цветовые области объединяются в общие поля.

02

Независимые области очистки

Цилиндр, сфера, эллипсоид или бокс. Перемещайте их отдельно, поворачивайте или привязывайте к Object3D. Мягкость края и сила очистки остаются под вашим контролем.

03

Сцена остаётся вашей

Без встроенной земли, моделей, интерфейса и собственного цикла анимации. Библиотека получает сцену и камеру, учитывает depth texture и рисует итоговую композицию.

02 / ПОДКЛЮЧЕНИЕ
import { MaskFieldClouds } from '@haku-lab/volumetric-clouds';

const clouds = new MaskFieldClouds(renderer, {
  settings: { cameraClear: true, density: 0.8 },
});

const area = clouds.addArea({
  shape: 'cylinder',
  position: [0, 2, 0],
  radius: 4.5,
  softness: 1.2,
});

clouds.setPreset('balance');
clouds.addTint({ shape: 'sphere', position: [6, 3, 0],
  radius: 7, color: '#67d1af' });
const light = clouds.addLight({ position: [0, 3, 0],
  color: '#73daff', radius: 8, intensity: 2 });

// Необязательно: привязать область к вашей модели.
// area.attach(myObject3D);

let previous;
renderer.setAnimationLoop(now => {
  const dt = previous === undefined
    ? 0 : Math.max(0, (now - previous) / 1000);
  previous = now;
  clouds.render(scene, camera, dt);
});

// При завершении: остановите цикл и вызовите clouds.dispose().
СОВМЕСТИМОСТЬ

Three.js r180 · WebGL2 · PerspectiveCamera и OrthographicCamera. До 128 областей на экземпляр, в зависимости от лимитов GPU. WebGPU, XR и logarithmic/reversed depth пока не поддерживаются.
