02 / INTEGRATE
import { VolumetricClouds } from '@haku-lab/volumetric-clouds';

const clouds = new VolumetricClouds(renderer, {
  settings: { cameraClear: true, density: 0.8 },
});

const area = clouds.addArea({
  shape: 'cylinder',
  position: [0, 2, 0],
  radius: 4.5,
  softness: 1.2,
});

// Optional: attach the area to your model.
// area.attach(myObject3D);

let previous;
renderer.setAnimationLoop(now => {
  const dt = previous === undefined
    ? 0 : Math.max(0, (now - previous) / 1000);
  previous = now;
  clouds.render(scene, camera, dt);
});

// On teardown: stop the loop and call clouds.dispose().
COMPATIBILITY

Three.js r180 · WebGL2 · PerspectiveCamera and OrthographicCamera. Up to 128 areas per instance. WebGPU, XR and logarithmic/reversed depth are not supported yet.
