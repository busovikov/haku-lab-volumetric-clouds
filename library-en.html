01

Clouds with light inside

A raymarched layer with varying cloud heights, procedural 3D noise and detail moving in opposing directions. Add up to 32 moving local lights and independent tint regions, combined into shared fields.

02

Independent clearing areas

Cylinders, spheres, ellipsoids or boxes. Move them independently, rotate them or attach them to an Object3D. Control edge softness and clearing strength.

No built-in terrain, models, UI or animation loop. Pass in your scene and camera; the library uses scene depth and renders the final composite.

02 / INTEGRATE
import { MaskFieldClouds } from '@haku-lab/volumetric-clouds';

const clouds = new MaskFieldClouds(renderer, {
  settings: { cameraClear: true, density: 0.8 },
});

const area = clouds.addArea({
  shape: 'cylinder',
  position: [0, 2, 0],
  radius: 4.5,
  softness: 1.2,
});

clouds.setPreset('balance');
clouds.addTint({ shape: 'sphere', position: [6, 3, 0],
  radius: 7, color: '#67d1af' });
const light = clouds.addLight({ position: [0, 3, 0],
  color: '#73daff', radius: 8, intensity: 2 });

// Optional: attach the area to your model.
// area.attach(myObject3D);

let previous;
renderer.setAnimationLoop(now => {
  const dt = previous === undefined
    ? 0 : Math.max(0, (now - previous) / 1000);
  previous = now;
  clouds.render(scene, camera, dt);
});

// On teardown: stop the loop and call clouds.dispose().
COMPATIBILITY

Three.js r180 · WebGL2 · PerspectiveCamera and OrthographicCamera. MaskFieldClouds: up to 128 clearing areas, 128 tint regions and 32 local lights. WebGPU, XR and logarithmic/reversed depth are not supported yet.
